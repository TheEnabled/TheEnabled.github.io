Mythos Manuscripts

An interactive journey unraveling ancient mythological scrolls and forgotten legends.

Role:
Core Programmer & Mechanics Designer
Engine / Tech:
Unity / C#
Genre:
Adventure / Narrative Mystery
Platform:
PC / WebGL

What the Game is About

Mythos Manuscripts immerses players in an epic world where lost mythologies are preserved within mystical scrolls and celestial archives.

As an archivist and investigator, players must reconstruct fragmented texts, solve cosmological riddles, and appease legendary deities. Blending narrative richness with exploration mechanics, the game challenges players to piece together lore clues and make decisive choices that reshape the fate of mortal and divine realms.

How to Play & Controls

  • Navigation: Use the Main Menu (Play, Options, Quit) to configure display settings and enter the game campaign.
  • Mouse / Keyboard Interaction: Left-click to inspect manuscript runes, turn illuminated pages, and interact with environmental relics.
  • Riddle & Sequence Solving: Arrange symbolic glyphs into the correct mythological order to reveal hidden passages and unlock ancestral powers.
  • Journal System: Consult the in-game archivist notebook to track discovered prophecies and active quests.

Sol's Key Contributions

Core Game Systems

Built the core game loop, manuscript pagination scripts, rune verification algorithms, and dynamic audio management system in Unity C#.

Level & Progression Flow

Designed the progression architecture, ensuring that each manuscript introduces new puzzle mechanics and atmospheric narrative pacing.

QA & Playtesting

Led comprehensive test passes for UI responsiveness, save/load state persistence, resolution scaling, and input boundary edge cases.
