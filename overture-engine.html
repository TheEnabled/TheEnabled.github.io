Overture Engine

A custom 3D game engine and interactive editor built from the ground up in C++ with DirectX.

Author & Role:
Sol Andrei William Tabboga (Engine Architecture)
Language & API:
C++ / DirectX
Architecture:
Dual Viewports, Scene Graph, OBJ Loader
Platform:
Windows 64-bit

Engineering Overview

Overture Engine is a 3D game engine and native editor designed and coded in C++ to develop a deep, first-principles understanding of graphics rendering pipelines, hardware resource management, math foundations (vectors, matrices, quaternions), and editor tooling.

Unlike using high-level commercial engines, constructing Overture required implementing the DirectX rendering device, managing vertex and index buffers, compiling HLSL shaders, and creating an integrated graphical user interface with scene hierarchy management and real-time execution states.

Core Architectural Features

Dual Viewport Rendering Pipeline

Renders two simultaneous viewports in real time: an Editor Viewport featuring a free-flying editor camera for scene composition, and an independent Game Viewport depicting the perspective of the player camera.

Scene Hierarchy & Visibility System

Manages entity trees with parent-child transform propagation. Includes per-object visibility toggles ([v]) and active selection states.

Custom 3D Mesh & OBJ Parser

Built-in asset pipeline capable of parsing and generating geometry for complex 3D meshes (including standard benchmarks like the Stanford bunny, armadillo, teapot) as well as geometric primitives.

Simulation State Machine

Complete execution controls supporting Play, Pause, Step (frame-by-frame), and Stop modes, essential for deterministic debugging and gameplay validation.

Property Inspector

Dynamic inspection panel reflecting live object transforms, rendering properties, and component configurations for entities selected in the scene graph.

Project / Asset Library

File system browser organizing Objects, Shaders, Textures, and Images with hot-reloading capabilities for rapid asset integration.

Technical Skills Demonstrated

  • DirectX API Programming: Swap chain management, render targets, depth-stencil buffers, and rasterizer states.
  • 3D Mathematics: Matrix mathematics (World-View-Projection), vector calculus, frustum culling, and camera transformations.
  • Memory Management & C++ Performance: Cache-coherent data structures, smart pointers, and strict resource cleanup.
  • Developer Tooling: Designing an intuitive editor layout suited for game developers and level designers.
