Custom Engine: Overture Engine

DirectX 3D Game Engine & Editor built from scratch in C++

C++ DirectX Engine Architecture

Low-Level Systems & Graphics Pipeline

Overture Engine demonstrates foundational expertise in low-level game engine architecture, graphics APIs, and editor tool development:

  • Dual Viewport Pipeline: Separate real-time Editor Viewport and Game Viewport cameras.
  • Scene Hierarchy Graph: Dynamic entity management, parent-child scene graph traversal.
  • 3D Mesh & OBJ Parser: Custom loading and rendering for 3D meshes (Stanford bunny, armadillo, teapot).
  • Real-time State Machine: Play, Pause, Step-by-frame, and Stop execution modes.
  • Inspector & Asset Library: Object property reflection, shader management, and texture bindings.
